# YouTube 자료를 인사이트 근거로 쓰는 방법

목표는 영상 내용을 베끼는 것이 아니라, 내부 차트를 해석할 관점 하나를 얻는 것입니다. 영상은 “사례/맥락”이고, 판단의 중심은 오늘 만든 내부 차트입니다.

## Chrome에서 가져오는 순서

1. YouTube에서 수업 주제와 관련 있는 공개 영상을 엽니다.
   - 예: 데이터 분석, 교육 운영, 상담 전환, AI 업무 자동화, 고객 경험
2. 공유 버튼을 눌러 URL을 복사합니다.
3. NotebookLM에서 소스 추가를 누르고 URL을 넣습니다.
4. 영상 자막 또는 전사가 읽히는지 확인합니다.
5. 자막이 잡히지 않으면 영상 전체를 넣으려 하지 말고, 직접 본 핵심 구간을 3~5줄로 메모해 넣습니다.

## 자막이 안 잡힐 때 대체 방식

아래 양식으로 직접 메모를 만들어 NotebookLM에 넣습니다.

```text
영상 제목:
URL:
참고 구간:
핵심 내용 3줄:
우리 차트와 연결되는 지점:
단정하면 안 되는 점:
```

## NotebookLM에 물어볼 질문

이 영상에서 바인그룹의 센터·채널 성과 분석에 참고할 수 있는 관점 3개를 뽑아줘.
각 관점이 우리 내부 차트의 어떤 부분을 해석하는 데 도움이 되는지 연결해줘.
영상만으로 단정할 수 없는 부분은 한계로 표시해줘.

## 제출할 때 남길 것

- 영상 제목:
- URL:
- 참고한 구간 또는 핵심 문장:
- 내부 차트와 연결한 이유:
- 실제 액션으로 바꿀 수 있는 점:

## 주의

- 영상 원문을 길게 복사해 제출하지 않습니다.
- 출처를 남기고, 핵심 관점만 요약합니다.
- 내부 숫자와 연결되지 않는 일반론은 보고 문장에서 제외합니다.
