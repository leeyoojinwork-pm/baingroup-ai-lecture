1

3
다음 질문 만들기

추가로 확인할 데이터와 행동 후보를 정리합니다.

아래는 신규 교육 홍보 채널 데이터입니다.

채널별 문의 수 / 상담 수 / 등록 수:

- 네이버광고: 90 / 57 / 28

1. 등록 수 기준으로 보면 어떤 채널이 좋아 보이는지 정리해줘.
2. 상담 후 등록 전환율 기준으로 보면 판단이 어떻게 달라지는지 계산해줘.

오늘은 숫자를 보고 네 가지 판단을 해봅니다.

어떤 숫자를 비교할까?

센터·채널·과정 중 하나를 골라 문의 수, 상담 수, 등록 수를 비교합니다.

비율로 보면 판단이 바뀔까?

등록 수만 보지 않고 상담 후 등록 전환율, 전월 대비 증감률처럼 기준을 바꿉니다.

어떤 차트로 보여줄까?

막대는 비교, 선은 추이, 누적은 구성 비중을 보여줄 때 씁니다.

보고 문장은 어떻게 쓸까?

숫자 근거, 눈에 띄는 차이, 확인할 점, 다음 행동을 한 문장으로 연결합니다.

보안 데이터는 마지막에 별도로 체크합니다. 오늘의 중심은 숫자 → 비교 → 차트 → 보고 문장입니다.
