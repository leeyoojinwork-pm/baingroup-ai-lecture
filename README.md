# 바인그룹 생성형 AI 강의안

실시간 온라인 AI 교육용 HTML 강의안입니다.

- 1차수 주제: 업무 문서 작성 자동화 AI
- 2차수 주제: AI 데이터 처리와 분석
- 3차수 주제: 데이터 분석과 시각화 with AI
- 활용 도구: ChatGPT, Gemini
- 교육 대상: 바인그룹 전사 임직원
- 교육 시간: 90분

## 구성

### 1차수

- 강사 소개
- 교안 링크 안내
- 학습목표 안내
- ChatGPT와 Gemini 역할 비교
- 업무 폴더 설계
- 문서 자동화 시연 및 실습
- Padlet 제출 흐름

### 2차수

- 데이터 분석과 전처리 개념
- ChatGPT, Gemini, Excel 역할 구분
- 바인그룹형 센터·채널·매출 샘플 데이터 실습
- 전처리, 계산 열, 피벗테이블 설계
- 인사이트 도출과 5문장 보고서 초안
- 개인정보 익명화와 AI 결과 검수

### 3차수

- 2차수 정리 데이터와 예습 데이터 연결
- 분석 질문 설계
- 정형/비정형 데이터와 전처리 복습
- ChatGPT/Gemini/Excel·Sheets 역할 구분
- 피벗 또는 요약표 만들기
- 차트 선택과 인사이트 해석
- 보고 문장 5줄 작성
- Padlet 제출 흐름
