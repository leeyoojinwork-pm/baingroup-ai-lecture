# 바인그룹 강의 설계 포커스 메모

## 이전 2차수/3차수에서 확인한 핵심 포커스

### 1. 수강생 질문에서 출발한다

2차수와 3차수는 모두 도구 기능 목록에서 시작하지 않고, 사전 설문과 현업 고민에서 시작했다.

- 여러 파일과 시스템 자료를 어떻게 모을지
- 엑셀/구글시트 데이터를 어떻게 정리할지
- 보안 때문에 원본 데이터를 AI에 넣기 어려울 때 어떻게 할지
- 피벗, 계산, 차트, 보고 문장으로 어떻게 연결할지
- 완성본이 아니어도 어디까지 제출하면 되는지

이번 차수도 첫 흐름은 “오늘 해결할 현업 질문”이어야 한다.

### 2. 도구 설명보다 실무 산출물을 먼저 보여준다

2차수의 중심은 `정리된 표`, 3차수의 중심은 `차트와 보고 문장`이었다. 도구는 산출물을 만들기 위한 수단으로만 등장했다.

이번 차수도 “ChatGPT/Gemini로 리서치하는 법”이 아니라 아래 산출물을 먼저 약속해야 한다.

- 리서치 질문 1개
- 출처가 남는 자료 목록
- 경쟁사/시장 비교표
- 시사점 3개
- 다음 액션 1개
- 보고용 5문장

### 3. 개념은 짧게, 바로 손을 움직이게 한다

이전 자료의 좋은 흐름은 `개념 1장 → 바로 따라 하기 1장 → 결과물 확인 1장`이었다. 설명 장표가 길게 이어지면 온라인 강의에서 집중이 떨어진다.

이번 차수도 각 개념 뒤에는 즉시 실행 페이지를 붙인다.

- 리서치 질문이란? → 내 업무 질문 1개 고르기
- 좋은 출처란? → 출처 3개 고르기
- 비교표란? → 항목 4개짜리 표 만들기
- 시사점이란? → “그래서 무엇을 할까?” 3줄 쓰기

### 4. AI와 사람의 역할을 분리한다

2차수/3차수에서 반복된 메시지는 “AI가 다 하는 것”이 아니라 “AI가 초안을 만들고 사람이 기준과 검산을 담당한다”였다.

이번 차수에도 같은 구조를 적용한다.

| 역할 | 담당 |
| --- | --- |
| ChatGPT/Gemini | 검색 질문 정리, 비교 항목 제안, 요약 초안 작성 |
| 사람 | 출처 신뢰도 판단, 회사 맥락 반영, 최종 액션 선택 |
| 표/문서 | 출처, 비교 기준, 판단 근거를 남기는 작업 공간 |

### 5. 보안은 별도 주제가 아니라 모든 실습의 기본값이다

이전 차수에서 보안은 “하면 안 된다”가 아니라 “어떻게 바꿔서 질문할 것인가”로 다뤘다. 이번 차수도 내부 자료를 그대로 외부 AI에 올리는 흐름은 피한다.

- 원본 데이터 대신 요약값 사용
- 고객명, 연락처, 계약번호 제거
- 실제 수치 대신 범위/비율/샘플로 치환
- 외부 리서치 자료는 출처 URL과 확인일을 남김
- AI 답변은 반드시 원문 출처와 대조

### 6. 완성본보다 진행 단계를 제출 가능하게 한다

2차수/3차수 모두 “막히면 막힌 단계도 제출 가능”하게 설계했다. 온라인 PBL에서는 이 기준이 참여율을 살린다.

이번 차수 제출 기준도 이렇게 둔다.

- 완성 제출: 비교표 + 시사점 3개 + 보고 문장 5줄
- 중간 제출: 리서치 질문, 출처 링크 3개, 비교표 초안, 막힌 지점 중 하나

## 이번 차수에 적용할 강의 포커스

### 차수 포커스

4차수는 `외부 리서치` 수업이다. 하지만 주제는 “검색 잘하기”가 아니라 **내부 데이터에서 생긴 질문을 외부 근거로 검증하고, 전략 시사점으로 바꾸는 것**이다.

### 한 문장 목표

3차수에서 만든 내부 분석 결과에 외부 시장/경쟁사/고객 자료를 붙여, 바인그룹 업무 판단에 쓸 수 있는 비교표와 실행 아이디어를 만든다.

### 수업 스토리

1. 내부 데이터만 보면 “무슨 일이 일어났는지”는 보인다.
2. 그런데 “왜 그런지”, “다른 곳은 어떻게 하는지”는 외부 근거가 필요하다.
3. 그래서 리서치 질문을 만들고, 믿을 수 있는 출처를 고른다.
4. AI에게 요약을 맡기되, 출처와 기준은 사람이 검증한다.
5. 마지막에는 비교표, 시사점, 다음 액션으로 남긴다.

### 90분 운영안

| 시간 | 흐름 | 수강생 행동 | 결과물 |
| --- | --- | --- | --- |
| 0-10분 | 3차수 결과 복습 | 내부 데이터에서 나온 질문 확인 | 오늘의 리서치 질문 후보 |
| 10-20분 | 리서치 질문 정의 | 시장/경쟁사/고객/채널 중 하나 선택 | 질문 1개 |
| 20-35분 | 출처 찾기 | 공식 자료, 기사, 보고서, 홈페이지 중 3개 선별 | 출처표 |
| 35-50분 | 비교표 만들기 | 항목, 기준, 근거 문장을 표로 정리 | 비교표 초안 |
| 50-65분 | AI 요약/시사점 | ChatGPT/Gemini로 요약하고 시사점 도출 | 시사점 3개 |
| 65-80분 | 검증/보고 문장 | 원문과 AI 답변 대조, 보고 문장 작성 | 5문장 초안 |
| 80-90분 | 제출/공유 | 완성본 또는 중간 결과 업로드 | 제출물 |

## 이번 차수 장표 제작 체크리스트

- 첫 5장 안에 “오늘 왜 외부 리서치를 하는가”가 보여야 한다.
- 목차는 `INTRO → 질문 정의 → 출처 검증 → 비교표 → 시사점 → 제출` 흐름으로 간다.
- 각 섹션은 `개념 → 바로 따라 하기 → 예상 결과물` 3단으로 만든다.
- 실습 페이지에는 반드시 `무엇을 열기 / 무엇을 복사하기 / 어디에 붙이기 / 무엇을 제출하기`가 들어간다.
- 운영 내부용 멘트는 장표에 넣지 않고 강사용 대본으로 분리한다.
- 90분 기준 장표는 60~75장 안쪽으로 유지한다.
- 장표 한 장에는 핵심 문장 1개, 카드 3~4개, 표 1개 이하를 원칙으로 한다.
- 사전 설문 니즈가 최소 1번 이상 직접 연결되어야 한다.
- 마지막 제출 페이지에는 완성 제출과 중간 제출 기준을 나란히 둔다.
