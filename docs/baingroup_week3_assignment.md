## 제출물

1. 내가 고른 분석 질문 1개
2. 어떤 파일을 기준으로 분석했는지 파일명 또는 데이터 출처
3. 피벗 또는 요약표 캡처 1개
4. 차트 캡처 1개
5. AI에게 사용한 프롬프트 1개
6. 보고 문장 5줄

## 제출 예시

- 질문: 센터별 상담 전환율 차이가 큰 이유는 무엇인가?
- 차트: 센터별 전환율 막대그래프
- 인사이트: 강남센터와 분당센터의 전환율이 높고, 네이버광고 유입은 상담 수는 많지만 등록 전환이 낮습니다.
- 다음 액션: 광고 유입 상담 스크립트를 점검하고, 지인추천 채널의 운영 방식을 비교합니다.

## 제출 기준

완성도가 낮아도 괜찮습니다. 오늘은 여러 데이터 중 하나를 고르거나 연결 기준을 잡고, **질문 → 표 → 차트 → 문장** 흐름을 끝까지 한 번 연결하는 것이 목표입니다.

제출 전에 아래 3가지만 확인합니다.

- 완전성: 필수 열과 값이 빠지지 않았는가?
- 일관성: 센터명, 채널명, 날짜 표기가 같은 기준으로 정리되었는가?
- 추적성: 어떤 파일 또는 출처를 기준으로 분석했는지 남겼는가?
