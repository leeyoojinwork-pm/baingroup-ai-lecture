# 3차수 자료 - 데이터 분석과 시각화 with AI

## 2차수에서 3차수로 이어지는 흐름

2차수에서는 여러 파일/채널 데이터를 한 표에서 만날 수 있게 정리했습니다.
3차수에서는 그 정리된 데이터 또는 예습 데이터 묶음을 보고 **분석 질문, 요약표, 차트, 보고 문장**까지 만듭니다.

## 오늘의 목표

데이터를 많이 다루는 것이 목표가 아니라, **하나의 판단으로 이어지는 분석 흐름**을 완성하는 것이 목표입니다.

1. 여러 예습 데이터 중 먼저 볼 파일을 고릅니다.
2. AI에게 열 구조와 분석 질문 후보를 뽑게 합니다.
3. Excel 또는 Google Sheets에서 계산 열과 피벗을 확인합니다.
4. 차트 1개와 보고 문장 5줄을 만듭니다.
5. 완성본 또는 중간 진행 상태를 Padlet에 남깁니다.

## 핵심 설명. 숫자는 비교할 때 의미가 생깁니다

3차수는 차트를 예쁘게 만드는 수업이 아니라, **숫자를 보고, 비교하고, 그래서 무슨 말을 할 수 있는지 정리하는 수업**입니다.

수업에서는 먼저 아래 표만 보여주고 질문합니다.

| 채널 | 문의 수 | 상담 수 | 등록 수 |
| --- | ---: | ---: | ---: |
| 블로그 | 100 | 40 | 10 |
| 검색광고 | 80 | 50 | 20 |
| 지인추천 | 30 | 25 | 18 |

**강사 질문**

- 등록 수만 기준으로 보면 어느 채널을 우선 운영하겠습니까?
- 문의 수가 많은 채널이 정말 좋은 채널일까요?
- 상담 후 등록으로 이어진 비율을 보면 판단이 달라질까요?

그다음 등록 전환율을 같이 계산합니다.

| 채널 | 계산 | 상담 후 등록 전환율 |
| --- | --- | ---: |
| 블로그 | 10 / 40 | 25% |
| 검색광고 | 20 / 50 | 40% |
| 지인추천 | 18 / 25 | 72% |

**보고 문장 예시**

> 등록 수는 검색광고가 가장 많지만, 상담 후 등록 전환율은 지인추천이 가장 높습니다.

이 한 장면이 오늘 수업 전체의 기준입니다. 표를 열면 바로 차트를 만드는 것이 아니라, 먼저 “어떤 숫자를 비교해야 판단이 달라지는가?”를 찾습니다.

## 참고 자료에서 선별 반영한 포인트

데이터 매니저 과정 자료는 긴 과정이라 대부분은 이번 90분 수업 범위를 넘습니다. 3차수에는 아래 세 가지만 얇게 반영합니다.

1. **데이터 품질**: 분석 전 완전성, 일관성, 추적성을 확인합니다.
2. **정제·검증**: 날짜, 센터명, 채널명, 누락값, 중복값을 먼저 확인합니다.
3. **출처 관리**: 여러 파일을 취합할 때 source_file, source_channel처럼 출처를 남깁니다.

## 오프닝 흐름. 한 장에 하나씩 보기

수강생이 한 화면에서 여러 결론을 동시에 읽지 않도록, 초반부는 판단 흐름을 잘게 나눕니다.

1. **상황 가정**: 나는 보유 종목 3개를 점검하는 개인 투자자입니다.
2. **숫자만 보기**: 최근 1주, 최근 1개월 등락률처럼 눈앞에 보이는 숫자만 봅니다.
3. **행동 선택지**: 할 수 있는 행동은 매수, 매도, 보유 세 가지입니다.
4. **판단 과정**: 숫자 -> 행동 후보 -> 판단 기준 -> 관점 후보 -> 내 문장 순서로 생각을 만듭니다.
5. **AI 역할**: AI는 정답을 찍어주는 도구가 아니라, 내가 선택할 수 있는 생각의 후보를 넓혀주는 보조도구입니다.
6. **업무 데이터 전환**: 같은 방식을 모집 채널 데이터에 적용합니다.
7. **원숫자 보기**: 문의 수, 상담 수, 등록 수를 먼저 그대로 봅니다.
8. **비율로 다시 보기**: 상담 후 등록 전환율로 바꾸면 판단이 달라질 수 있음을 보여줍니다.
9. **인사이트 문장**: 숫자 근거와 다음 확인 방향을 한 문장으로 정리합니다.

## 실습 1. 분석 질문 정하기

**진행 순서**

1. ChatGPT 또는 Gemini를 엽니다.
2. `01_RAW_center_channel_performance_sample.xlsx`를 먼저 올립니다.
3. 아래 프롬프트를 붙여 넣습니다.
4. 질문 후보 5개 중 오늘 풀 질문 1개를 고릅니다.
5. 나온 질문과 추천 이유를 저장합니다.

**복사 프롬프트**

```
예습 데이터가 여러 파일로 나뉘어 있습니다. 각 파일의 열 이름과 일부 행을 보고, 바인그룹 교육/상담/운영 업무에서 답할 수 있는 분석 질문 5개를 제안해줘.

조건:
1. 어떤 파일을 먼저 분석하면 좋을지 추천해줘.
2. 센터별, 과정별, 채널별 비교 질문을 포함해줘.
3. 단순 현황 질문과 의사결정 질문을 구분해줘.
4. 오늘 90분 실습에서 가장 적합한 질문 1개를 추천해줘.
5. 추천 이유를 "데이터로 확인 가능함 / 차트로 설명 가능함 / 다음 액션으로 연결 가능함" 기준으로 설명해줘.
```

## 실습 2. 피벗/차트 만들기

**진행 순서**

1. `04_실습용_분석_대시보드_가상.xlsx`를 엽니다.
2. `분석용_계산열` 시트에서 전환율, 환불률 계산 열을 확인합니다.
3. 센터별 또는 채널별 피벗을 만듭니다.
4. 막대 차트 또는 꺾은선 차트 1개를 만듭니다.
5. 숫자가 맞는지 3~4행만 직접 검산합니다.

**복사 프롬프트**

```
이 데이터로 센터별 전환율과 환불률을 비교하려고 해.

1. 필요한 계산 열을 정의해줘.
2. Excel 또는 Google Sheets에서 만들 피벗 기준을 알려줘.
3. 어떤 차트를 쓰면 좋은지 추천해줘.
4. 차트 제목과 축 이름까지 제안해줘.
5. 숫자가 맞는지 사람이 검산해야 할 항목도 체크리스트로 정리해줘.
```

## 실습 3. 인사이트와 보고 문장 만들기

**진행 순서**

1. 내가 만든 피벗표 또는 차트의 핵심 숫자를 복사합니다.
2. ChatGPT 또는 Gemini에 아래 프롬프트를 붙입니다.
3. 보고 문장 5줄을 받습니다.
4. 숫자 근거와 다음 액션이 실제 데이터와 맞는지 확인합니다.
5. Padlet에 캡처와 문장을 올립니다.

**복사 프롬프트**

```
아래 요약표를 바탕으로 보고서에 넣을 인사이트를 작성해줘.

작성 기준:
1. 첫 문장은 결론부터 말해줘.
2. 숫자 근거를 반드시 포함해줘.
3. 원인 가설과 확인 필요 사항을 구분해줘.
4. 다음 액션을 1개만 제안해줘.
5. 임원 보고용 5문장으로 정리해줘.
```
