# 3차수 자료 - 데이터 분석과 시각화 with AI

## 오늘의 목표

2차수에서 만든 정리된 표 또는 여러 개의 예습 데이터 파일을 바탕으로, 바인그룹 업무에서 바로 설명 가능한 **분석 질문, 요약표, 차트, 보고 문장**을 만듭니다.

## 오늘 만들 결과물

1. 분석 질문 1개
2. 피벗 또는 요약표 1개
3. 차트 1개
4. AI 인사이트 초안 1개
5. 최종 보고 문장 5줄

## 실습 파일

예습 데이터는 한 파일이 아닐 수 있습니다. 매출/상담/후기/운영 자료처럼 여러 파일로 나뉘어 있으면, 먼저 파일별 역할과 연결 기준을 확인한 뒤 하나의 분석 질문으로 좁힙니다.

- `01_RAW_센터채널성과_가상.csv`
- `02_RAW_수강후기문의_가상.csv`
- `03_RAW_운영지표_가상.csv`
- `04_실습용_분석_대시보드_가상.xlsx`

## 실습 1. 분석 질문 정하기

**복사 프롬프트**

```
예습 데이터가 여러 파일로 나뉘어 있습니다. 각 파일의 열 이름과 일부 행을 보고, 바인그룹 교육/상담/운영 업무에서 답할 수 있는 분석 질문 5개를 제안해줘.

조건:
1. 어떤 파일을 먼저 분석하면 좋을지 추천해줘.
2. 센터별, 과정별, 채널별 비교 질문을 포함해줘.
3. 단순 현황 질문과 의사결정 질문을 구분해줘.
4. 오늘 90분 실습에서 가장 적합한 질문 1개를 추천해줘.
5. 추천 이유를 "데이터로 확인 가능함 / 차트로 설명 가능함 / 다음 액션으로 연결 가능함" 기준으로 설명해줘.
```

## 실습 2. 피벗/차트 만들기

**복사 프롬프트**

```
이 데이터로 센터별 전환율과 환불률을 비교하려고 해.

1. 필요한 계산 열을 정의해줘.
2. Excel 또는 Google Sheets에서 만들 피벗 기준을 알려줘.
3. 어떤 차트를 쓰면 좋은지 추천해줘.
4. 차트 제목과 축 이름까지 제안해줘.
5. 숫자가 맞는지 사람이 검산해야 할 항목도 체크리스트로 정리해줘.
```

## 실습 3. 인사이트와 보고 문장 만들기

**복사 프롬프트**

```
아래 요약표를 바탕으로 보고서에 넣을 인사이트를 작성해줘.

작성 기준:
1. 첫 문장은 결론부터 말해줘.
2. 숫자 근거를 반드시 포함해줘.
3. 원인 가설과 확인 필요 사항을 구분해줘.
4. 다음 액션을 1개만 제안해줘.
5. 임원 보고용 5문장으로 정리해줘.
```

## 제출 기준

- 완성본 제출: 피벗/차트 캡처 + 보고 문장 5줄
- 중간 제출 가능: 분석 질문, 프롬프트, 막힌 지점 중 하나만 제출해도 됩니다.

## 다음 차수 연결

3차수에서 만든 차트와 보고 문장을 바탕으로, 4차수에서는 외부 리서치 자료를 붙여 시장/경쟁사 비교와 전략 시사점으로 확장합니다.
