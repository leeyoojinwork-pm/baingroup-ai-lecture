# 바인그룹 4차수 모범 제출 예시

## 사용 목적

이 문서는 4차수 수업에서 수강생에게 보여줄 수 있는 **모범 제출 예시**입니다.  
목표는 “AI로 검색을 잘했다”가 아니라, **내부 데이터에서 생긴 질문을 외부 근거로 확인하고, 비교표와 실행 아이디어로 남기는 것**입니다.

실제 수업에서는 아래 예시를 Notion 과제 페이지에 접어 넣거나, 제출 예시 카드로 짧게 보여주면 됩니다.

## 모범 예시 1. 완성 제출형

### 주제

센터별 상담 전환율 차이를 줄이기 위한 외부 채널 운영 방식 리서치

### 내가 고른 리서치 질문

센터별 상담 전환율 차이가 있을 때, 교육 업계에서는 어떤 채널 운영 방식과 상담 전환 장치를 활용하고 있는가?

### 사용한 내부 단서

3차수 분석에서 센터별 상담 신청 수와 등록 전환율 차이가 확인되었다.  
특히 광고 유입은 상담 수는 많지만 등록 전환율이 낮고, 지인추천/재등록 채널은 상담 수는 적지만 등록 전환율이 높았다.

### 외부 리서치 출처표

| 구분 | 확인한 출처 | 확인한 내용 | 활용 판단 |
| --- | --- | --- | --- |
| 공식 홈페이지 | 경쟁 교육 브랜드의 상담/체험 신청 페이지 | 상담 전 랜딩페이지에서 커리큘럼, 후기, 무료 체험 안내를 먼저 보여줌 | 상담 전 기대 수준을 맞추는 장치로 참고 |
| 블로그/후기 | 학부모 후기, 수강 후기 게시글 | 상담 전 실제 후기와 결과 사례를 확인하고 문의하는 흐름이 많음 | 후기 콘텐츠가 전환 전 신뢰 요소로 작동할 가능성 |
| 광고/랜딩 | 검색 광고 랜딩 페이지 | 무료 진단, 레벨 테스트, 상담 예약 CTA가 반복됨 | 광고 유입 전환율 개선용 CTA 구조 참고 |
| 내부 데이터 | 센터별·채널별 상담 전환 데이터 | 광고 유입 대비 추천/재등록 전환율이 높음 | 외부 사례와 비교해 채널별 메시지를 다르게 설계 |

### 비교표

| 비교 항목 | 현재 바인그룹 데이터에서 보이는 상태 | 외부 리서치에서 확인한 운영 방식 | 적용 아이디어 |
| --- | --- | --- | --- |
| 광고 유입 | 상담 수는 많지만 등록 전환율이 낮음 | 진단/체험/후기 콘텐츠를 상담 전 노출 | 광고 랜딩에 “진단 → 후기 → 상담 예약” 순서 추가 |
| 지인추천 | 상담 수는 적지만 전환율이 높음 | 추천 후기와 성공 사례를 별도 콘텐츠로 노출 | 추천 유입용 후기 카드와 상담 스크립트 분리 |
| 센터별 차이 | 센터마다 전환율 편차가 있음 | 상담 전 안내 자료와 상담 스크립트 표준화 | 센터 공통 상담 전 안내 템플릿 제작 |
| 재등록 | 전환 가능성이 높지만 별도 관리 기준 부족 | 기존 고객 대상 리마인드, 혜택 안내 운영 | 재등록 대상자용 메시지 자동화 시나리오 설계 |

### 시사점 3개

1. 상담 전환율은 상담사의 역량만이 아니라, 상담 전 고객이 어떤 정보를 보고 왔는지에 영향을 받을 가능성이 있다.
2. 광고 유입은 양이 많아도 신뢰 형성 단계가 약하면 등록 전환으로 바로 이어지기 어렵다.
3. 센터별 전환율 편차를 줄이려면 상담 전 안내 자료와 상담 스크립트 기준을 공통화할 필요가 있다.

### 다음 액션 1개

광고 유입 고객용 상담 전 안내 페이지를 만들고, 후기/무료 진단/상담 예약 버튼 순서로 구성한 뒤 센터별 전환율 변화를 비교한다.

### 보고용 5문장

센터별 상담 전환율 차이는 단순 상담 수의 문제가 아니라, 유입 채널별 고객 기대 수준과 상담 전 정보 제공 방식의 차이와 연결될 가능성이 있습니다.  
외부 교육 브랜드 사례를 보면 광고 유입 고객에게는 후기, 진단, 체험 안내를 먼저 제공해 상담 전 신뢰를 형성하는 흐름이 반복적으로 확인됩니다.  
바인그룹 내부 데이터에서도 광고 유입은 상담 수가 많지만 전환율이 낮고, 추천/재등록 채널은 상대적으로 전환 가능성이 높게 나타났습니다.  
따라서 광고 유입 고객에게는 일반 상담 안내가 아니라, 후기와 진단 중심의 별도 랜딩/상담 스크립트를 적용해볼 필요가 있습니다.  
우선 1개 센터에서 광고 유입 고객용 상담 전 안내 템플릿을 적용하고, 다음 달 전환율 변화를 비교하는 방식으로 검증을 제안합니다.

### 제출물

- 리서치 질문 1개
- 출처표 4행
- 비교표 4행
- 시사점 3개
- 보고 문장 5줄

## 모범 예시 2. 완성 제출형

### 주제

수강 후기와 문의 데이터를 활용한 콘텐츠 주제 선정

### 내가 고른 리서치 질문

학부모와 수강생이 교육 브랜드를 선택할 때 중요하게 보는 정보는 무엇이며, 바인그룹 콘텐츠에는 어떤 주제를 우선 반영해야 하는가?

### 사용한 내부 단서

3차수에서 수강 후기와 문의 텍스트를 분류했을 때, “수업 난이도”, “성과 확인”, “강사 피드백”, “진도 관리” 관련 표현이 반복되었다.

### 외부 리서치 출처표

| 구분 | 확인한 출처 | 확인한 내용 | 활용 판단 |
| --- | --- | --- | --- |
| 공식 홈페이지 | 교육 브랜드의 과정 소개 페이지 | 커리큘럼보다 결과물, 수강 후 변화, 관리 방식이 전면에 배치됨 | 과정 설명보다 결과 중심 콘텐츠 필요 |
| 후기 채널 | 블로그/카페 후기 | 강사 피드백, 자녀 변화, 상담 경험이 후기의 주요 소재 | 후기 콘텐츠 분류 기준으로 활용 |
| FAQ | 경쟁 브랜드 FAQ | 난이도, 대상, 수업 방식, 보강 여부를 반복 설명 | 문의 감소용 FAQ 자동화에 활용 |
| 내부 데이터 | 후기/문의 텍스트 분류표 | 난이도와 피드백 관련 질문이 반복됨 | 콘텐츠 주제 우선순위 선정 |

### 비교표

| 비교 항목 | 내부 데이터에서 보이는 반복 질문 | 외부 사례에서 많이 보이는 설명 방식 | 적용 아이디어 |
| --- | --- | --- | --- |
| 난이도 | “우리 아이가 따라갈 수 있나요?” | 레벨 기준과 수업 전 진단을 안내 | 과정별 난이도 체크 카드 제작 |
| 성과 | “수업 후 무엇이 달라지나요?” | 결과물, 변화 사례, 수강 후기 노출 | 수강 전후 변화 사례 콘텐츠 제작 |
| 피드백 | “강사가 얼마나 봐주나요?” | 피드백 방식과 관리 주기를 안내 | 강사 피드백 프로세스 시각화 |
| 운영 | “보강이나 일정 변경은 되나요?” | FAQ와 상담 전 안내로 처리 | 자주 묻는 운영 질문 자동 응답 초안 |

### 시사점 3개

1. 교육 콘텐츠는 커리큘럼 설명만으로는 부족하고, 수강 전 불안을 줄이는 정보가 함께 필요하다.
2. 후기와 문의 데이터는 단순 감상문이 아니라, 콘텐츠 우선순위를 정하는 실무 데이터로 활용할 수 있다.
3. 자주 반복되는 문의는 FAQ, 상담 스크립트, 상세페이지 문구로 재사용하면 운영 부담을 줄일 수 있다.

### 다음 액션 1개

수강 후기와 문의를 `난이도/성과/피드백/운영` 4개 주제로 분류한 뒤, 각 주제별 FAQ와 상세페이지 문구 초안을 만든다.

### 보고용 5문장

수강 후기와 문의 데이터에서 반복되는 핵심 주제는 난이도, 성과, 강사 피드백, 운영 안내입니다.  
외부 교육 브랜드 사례에서도 커리큘럼 자체보다 수강 전 불안을 줄이는 정보와 결과 사례가 전면에 배치되는 경향이 확인됩니다.  
따라서 바인그룹 콘텐츠도 과정 소개만 강화하기보다, 학부모가 상담 전에 궁금해하는 질문을 먼저 해소하는 방향으로 정리할 필요가 있습니다.  
특히 난이도 기준, 수강 후 변화, 피드백 방식, 보강 안내는 FAQ와 상세페이지에 반복 활용할 수 있는 콘텐츠 자산입니다.  
다음 단계로 후기/문의 데이터를 4개 주제로 분류하고, 주제별 FAQ와 상담 스크립트 초안을 만드는 것을 제안합니다.

## 모범 예시 3. 중간 제출형

### 제출 상황

출처는 찾았지만 비교표까지 완성하지 못한 경우

### 내가 고른 리서치 질문

교육 상담 전환율을 높이기 위해 상담 전 페이지에는 어떤 정보가 먼저 보여야 하는가?

### 지금까지 한 것

1. 경쟁 교육 브랜드 홈페이지 2곳을 확인했다.
2. 상담 신청 전에 후기, 무료 진단, 커리큘럼, FAQ가 반복해서 노출되는 것을 확인했다.
3. 바인그룹 내부 데이터에서는 광고 유입 전환율이 낮은 편이라, 상담 전 정보 제공 방식과 연결해볼 수 있다고 판단했다.

### 아직 막힌 지점

비교표 항목을 어떻게 잡아야 할지 헷갈린다.  
현재 생각한 비교 항목은 `후기 노출`, `무료 진단`, `FAQ`, `상담 CTA`, `성과 사례`이다.

### 제출 가능 문장

아직 완성 비교표는 만들지 못했지만, 광고 유입 전환율 개선을 위해 상담 전 페이지에서 어떤 정보가 먼저 노출되는지 비교하는 방향으로 리서치를 진행 중입니다.

## 모범 예시 4. 보안 데이터 대응형

### 상황

내부 고객명, 연락처, 계약번호, 상담 메모가 포함되어 있어 원본 파일을 AI에 올릴 수 없는 경우

### AI에 올리지 않는 정보

- 고객명
- 연락처
- 계약번호
- 상세 상담 메모 원문
- 실제 결제 금액이 개인을 식별할 수 있는 경우

### AI에 줄 수 있는 형태

| 원본 항목 | 변환 방식 | AI에 줄 표현 |
| --- | --- | --- |
| 고객명 | 삭제 | 고객ID_001 |
| 연락처 | 삭제 | 없음 |
| 계약번호 | 삭제 | 없음 |
| 상담 메모 | 주제만 분류 | 난이도 문의 / 가격 문의 / 일정 문의 |
| 결제 금액 | 구간화 | 10만원 미만 / 10~30만원 / 30만원 이상 |
| 센터명 | 필요 시 유지 | 강남센터 / 분당센터 |

### AI에 넣을 프롬프트 예시

```
아래 데이터는 실제 고객정보를 제거하고 샘플화한 상담 데이터입니다.

원본 고객명, 연락처, 계약번호는 삭제했고,
상담 메모는 주제 분류값으로 바꿨습니다.

이 데이터를 보고 다음을 정리해줘.
1. 상담 주제별 빈도
2. 등록 전환율이 높은 주제
3. 센터별 차이
4. 추가 확인이 필요한 데이터 품질 이슈
5. 보고서에 넣을 5문장 요약
```

### 보고 문장 예시

개인정보가 포함된 원본 상담 데이터는 AI에 직접 업로드하지 않고, 고객 식별값을 제거한 샘플 데이터로 변환했습니다.  
상담 메모 원문은 주제 분류값으로 바꾸고, 결제 금액은 구간값으로 처리해 개인 식별 가능성을 낮췄습니다.  
이 방식은 원본을 보호하면서도 상담 주제별 빈도, 전환율, 센터별 차이를 확인할 수 있게 합니다.  
AI에게는 실제 고객 정보가 아니라 분석 가능한 구조와 기준만 제공하고, 최종 판단은 사람이 원본과 대조해 검산합니다.  
따라서 보안 데이터도 “그대로 업로드하지 않기”가 아니라, 안전한 분석 샘플로 바꾼 뒤 제한적으로 활용할 수 있습니다.

## Notion에 넣기 좋은 짧은 제출 예시 카드

### 완성 제출 예시

**질문**: 광고 유입 상담 전환율을 높이려면 상담 전 어떤 정보가 먼저 보여야 할까?  
**출처**: 경쟁 브랜드 홈페이지 2곳, 후기 채널 1곳, 내부 센터별 전환 데이터  
**결과물**: 출처표 4행, 비교표 4행, 시사점 3개, 보고 문장 5줄  
**다음 액션**: 광고 유입 고객용 상담 전 안내 템플릿을 1개 센터에서 테스트

### 중간 제출 예시

**질문**: 후기/문의 데이터에서 자주 나오는 불안 요소는 무엇인가?
