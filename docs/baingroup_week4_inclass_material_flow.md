# 바인그룹 4차수 수업 중 자료 요청·산출물 설계

## 운영 원칙

강의 중간중간 자료를 요청할 때는 “자료 주세요”로 끝내지 않고, **그 자료로 무엇을 만들지**를 바로 붙여 안내합니다.

자료 요청 문장은 항상 아래 구조로 말합니다.

1. 지금 필요한 자료
2. 원본이 부담스러울 때 대체 입력
3. 그 자료로 만들 산출물
4. 제출 기준

---

## 0. 오프닝 자료 요청

### 타이밍

수업 시작 5분 이내

### 요청할 자료

오늘 리서치와 비교표에 연결하고 싶은 업무 주제

### 수강생이 낼 수 있는 형태

- 실제 파일
- 파일명만
- 데이터 종류만
- 평소 궁금했던 질문 1문장

### 강사가 던질 말

```
오늘은 외부 리서치 수업이지만, 출발점은 여러분 업무 데이터입니다.
지금 채팅에 오늘 다뤄보고 싶은 자료나 주제를 하나 남겨주세요.

원본 파일을 올리지 않아도 됩니다.
예: 상담 전환 데이터, 월별 매출 데이터, 후기/문의 데이터, 센터별 운영 데이터
또는 “광고 유입이 왜 전환이 낮은지 보고 싶다”처럼 질문으로 남겨도 됩니다.
```

### 만들 산출물

오늘의 개인 리서치 질문 후보

### 제출 기준

주제 또는 질문 1개

---

## 1. 자료 요청 1: 내부 단서 잡기

### 타이밍

리서치 질문 정의 직전

### 요청할 자료

내부에서 이미 갖고 있는 단서

### 수강생이 낼 수 있는 형태

- 3차수에서 만든 차트/요약표 캡처
- 엑셀/시트의 열 이름
- 숫자 2~3개
- “어떤 현상이 있다”는 문장

### 강사가 던질 말

```
이제 외부 자료를 찾기 전에 내부 단서를 하나 잡겠습니다.
자료가 있는 분은 3차수에서 만든 차트나 요약표를 올려주세요.

자료를 올리기 어렵다면 아래 중 하나만 채팅에 적어주세요.
1) 비교하고 싶은 기준: 센터 / 과정 / 채널 / 월
2) 눈에 띄는 현상: 전환율 낮음 / 문의 증가 / 후기 부정어 증가
3) 확인하고 싶은 질문: 왜 이런 차이가 나는가?
```

### 만들 산출물

내부 단서 1개

### 예시 산출물

| 항목 | 예시 |
| --- | --- |
| 내부 단서 | 광고 유입은 상담 수는 많지만 등록 전환율이 낮다 |
| 비교 기준 | 채널별 |
| 다음 질문 | 광고 유입 고객에게 상담 전 어떤 정보가 부족한가? |

---

## 2. 자료 요청 2: 리서치 질문 만들기

### 타이밍

실습 1 시작

### 요청할 자료

내부 단서를 외부 리서치 질문으로 바꾸기 위한 업무 맥락

### 수강생이 낼 수 있는 형태

- 고객 유형
- 센터/과정/채널 중 비교 기준
- 경쟁사 또는 참고하고 싶은 브랜드명
- 확인하고 싶은 외부 정보 종류

### 강사가 던질 말

```
방금 잡은 내부 단서를 외부 리서치 질문으로 바꿔보겠습니다.
채팅에 아래 4가지 중 가능한 것만 남겨주세요.

1. 고객 유형: 학부모 / 수강생 / 기업 담당자 등
2. 비교 기준: 센터 / 과정 / 채널 / 월
3. 참고하고 싶은 브랜드나 경쟁사
4. 알고 싶은 외부 정보: 후기 / 가격 / 커리큘럼 / 상담 방식 / 광고 메시지
```

### 만들 산출물

외부 리서치 질문 1개

### 예시 산출물

```
광고 유입 고객의 등록 전환율을 높이기 위해,
교육 브랜드들은 상담 전 랜딩페이지에서 어떤 정보와 CTA를 먼저 보여주는가?
```

## 3. 자료 요청 3: 출처 모으기

### 타이밍

출처 검증 파트 직후

### 요청할 자료

리서치에 쓸 외부 출처 3개

### 수강생이 낼 수 있는 형태

- 공식 홈페이지 URL
- 기사 URL
- 보고서/통계 URL
- 경쟁사 페이지 캡처
- 검색어만 제출

### 강사가 던질 말

```
이제 출처를 모읍니다.
완벽한 자료를 찾으려고 오래 걸리지 말고, 5분 안에 후보 3개만 남깁니다.

가능하면 공식 홈페이지, 공공기관/협회 자료, 기사/보고서 순서로 찾아주세요.
링크를 못 찾았으면 검색어만 남겨도 됩니다.
```

### 만들 산출물

출처표

### 예시 산출물

| 출처 | 왜 봤는가 | 쓸 수 있는 내용 |
| --- | --- | --- |
| 경쟁 브랜드 상담 신청 페이지 | 상담 전 정보 구조 확인 | 후기, 무료 진단, CTA 순서 |
| 교육 트렌드 기사 | 시장 변화 확인 | 학부모 관심 키워드 |
| 내부 3차수 차트 | 내부 현상 확인 | 광고 유입 전환율 낮음 |

---

## 4. 자료 요청 4: 비교 기준 정하기

### 타이밍

비교표 작성 직전

### 요청할 자료

비교하고 싶은 항목 4개

### 수강생이 낼 수 있는 형태

- 비교 항목명만
- 경쟁사명만
- 내부 기준만
- AI가 추천한 비교 항목 캡처

### 강사가 던질 말

```
이제 자료를 그냥 모으는 단계에서 비교표로 바꿉니다.
비교 항목을 4개만 고르겠습니다.

예:
- 상담 전 제공 정보
- 후기 노출 방식
- 무료 진단/체험 여부
- 상담 예약 CTA
- 가격/혜택 안내
- FAQ 구성
```

### 만들 산출물

비교표 초안

### 예시 산출물

| 비교 항목 | 우리 내부 단서 | 외부에서 본 방식 | 적용 아이디어 |
| --- | --- | --- | --- |
| 후기 노출 | 후기 데이터는 있으나 상담 전 연결 약함 | 상담 신청 전 후기 카드 노출 | 광고 랜딩에 후기 3개 배치 |
| 무료 진단 | 상담 단계에서만 안내 | 랜딩 첫 화면에서 진단 제안 | 상담 전 진단 CTA 추가 |

---

## 5. 자료 요청 5: 시사점 만들기

### 타이밍

비교표를 만든 직후

### 요청할 자료

비교표에서 가장 눈에 띄는 차이 1개

### 수강생이 낼 수 있는 형태

- 비교표 캡처
- 차이점 1문장
- “우리에게 적용할 수 있는 것” 1개

### 강사가 던질 말

```
비교표를 만들었다면, 이제 결론을 하나만 뽑습니다.
채팅에 아래 문장 중 하나를 완성해서 남겨주세요.

“외부 사례와 비교했을 때 우리에게 부족한 것은 ______ 입니다.”
“바로 적용해볼 수 있는 것은 ______ 입니다.”
“추가로 확인해야 할 것은 ______ 입니다.”
```

### 만들 산출물

시사점 3개 중 1개

### 예시 산출물

```
외부 사례와 비교했을 때 우리에게 부족한 것은 상담 전 후기/진단 정보를 먼저 보여주는 구조입니다.
```

## 6. 자료 요청 6: 보고 문장 만들기

### 타이밍

마지막 실습

### 요청할 자료

비교표 또는 시사점 1개

### 수강생이 낼 수 있는 형태

- 비교표 캡처
- 시사점 1개
- AI가 만든 초안
- 막힌 지점

### 강사가 던질 말

```
마지막으로 보고 문장 5줄을 만듭니다.
완성 비교표가 없어도 괜찮습니다.
지금 가진 것 중 하나만 넣고 문장으로 바꿔보겠습니다.

1. 내부 단서
2. 외부 출처에서 확인한 점
3. 비교해서 달라 보인 점
4. 그래서 제안할 액션
```

### 만들 산출물

보고용 5문장

### 예시 산출물

```
광고 유입 상담 전환율은 상담 수보다 상담 전 정보 제공 방식과 연결될 가능성이 있습니다.
외부 교육 브랜드 사례에서는 상담 신청 전 후기, 무료 진단, FAQ를 먼저 보여주는 흐름이 반복적으로 확인됩니다.
바인그룹 내부 데이터에서는 광고 유입 상담 수는 많지만 등록 전환율이 낮아, 상담 전 신뢰 형성 장치가 부족한지 확인할 필요가 있습니다.
따라서 광고 유입 고객에게는 후기와 진단 중심의 별도 안내 템플릿을 적용해보는 것이 적절합니다.
우선 1개 센터에서 해당 템플릿을 적용하고 다음 달 전환율 변화를 비교하는 방식으로 검증을 제안합니다.
```

## 최종 제출 안내

### 완성 제출

- 리서치 질문 1개
- 출처표 3개 이상
- 비교표 1개
- 시사점 3개
- 보고 문장 5줄

### 중간 제출

아래 중 하나만 제출해도 인정합니다.

- 오늘 고른 질문 1개
- 출처 링크 1개 이상
- 비교표 초안
- 시사점 1개
- 막힌 지점

### 강사가 마지막에 할 말

```
오늘 제출은 완성도 평가가 아닙니다.
내부 단서에서 출발해서 외부 근거를 붙이고,
그걸 비교표나 보고 문장으로 한 단계라도 바꿨다면 제출 가능합니다.

완성본이 아니어도 질문, 출처, 비교표 초안, 막힌 지점 중 하나만 남겨주세요.
```
