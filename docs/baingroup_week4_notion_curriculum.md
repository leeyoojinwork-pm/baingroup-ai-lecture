# [바인그룹] 실시간 온라인 AI 교육 4차수
## AI 스마트 리서치 자동화

4차수는 3차수에서 만든 내부 데이터 인사이트를 외부 리서치 근거로 보강하는 시간입니다.
이번 시간의 목표는 “자료를 많이 찾기”가 아니라, 내부 숫자가 말하는 신호를 시장·고객·경쟁 맥락에서 확인하고 보고 문장으로 확장하는 것입니다.
3차수 EDA에서 발견한 이상치·결측치·반복 패턴은 4차수에서 외부 기준점으로 확인합니다. 외부 자료는 정답이 아니라 내부 숫자를 해석하기 위한 비교 기준입니다.

## 오늘 만들 결과물
1. 외부 리서치 질문 3개
2. EDA 신호를 외부 기준점으로 바꾸는 확인표 1개
3. 소스 로그 3개 이상
4. NotebookLM 근거 브리핑 1개
5. Gemini/ChatGPT 기반 비교표 1개
6. 내부 숫자 + 외부 근거 + 다음 액션이 들어간 보고 문장 3개

## EDA에서 외부 데이터로 넘어가는 기준
- 이상치: 값이 튀면 먼저 입력 오류인지 보고, 이후 지역 행사, 시즌 수요, 경쟁사 메시지, 검색 흐름과 비교합니다.
- 결측치: 값이 비거나 0으로 찍히면 수집 방식, 채널 기록 기준, 공식 운영 자료와 비교해 “비어 있는 값”인지 “의미 있는 0”인지 나눕니다.
- 패턴·관계: 내부 숫자끼리 보이는 관계를 고객 언어, 시장 변화, 경쟁사 메시지와 대조합니다.
- 보고 문장: “내부 신호 + 외부 기준 + 판단 + 다음 액션” 순서로 씁니다.

## 복사 프롬프트
### 1. 리서치 질문 만들기
첨부한 week4_external_research_pack.xlsx의 01_내부인사이트후보 시트를 보고, 외부 리서치로 확인해야 할 질문 5개를 만들어 주세요. 각 질문은 내부 데이터에서 관찰한 신호, 외부에서 확인해야 할 근거, 찾아볼 자료 유형, 의사결정에 주는 의미, 오늘 90분 안에 확인 가능한지 여부로 정리해 주세요.

### 1-1. EDA 신호를 외부 기준점으로 바꾸기
내부 데이터에서 발견한 이상치, 결측치, 반복 패턴을 보고 외부 자료로 확인해야 할 기준점을 정리해 주세요.

결과는 아래 표로 작성해 주세요.

| 내부 신호 | 확인할 외부 기준 | 찾아볼 자료 | 판단 질문 | 다음 액션 |
|---|---|---|---|---|

주의:
- 외부 자료는 결론을 대신 내리는 자료가 아니라 내부 숫자를 해석하기 위한 기준점으로만 사용해 주세요.
- 데이터 오류 가능성과 실제 시장 변화 가능성을 나눠서 적어 주세요.
- 오늘 90분 안에 확인 가능한 자료부터 우선순위를 매겨 주세요.

### 2. 보안 샘플 데이터 만들기
아래 원본 데이터 구조를 유지하되, 개인정보와 민감 정보를 제거한 가짜 샘플 데이터 20행을 만들어 주세요. 이름, 연락처, 주소, 계좌, 상세 상담 내용처럼 개인이 특정될 수 있는 값은 삭제하거나 범주형 값으로 바꿔 주세요.

### 3. NotebookLM 근거 브리핑
업로드한 소스만 근거로 사용해서 확인 질문, 소스에서 확인된 근거, 내부 데이터와 연결되는 지점, 한계/주의, 보고서 문장 초안을 표로 정리해 주세요. 근거가 부족한 내용은 추측하지 말고 “근거 부족”이라고 표시해 주세요.

### 4. 보고 문장 만들기
내부 데이터 신호와 외부 리서치 근거를 합쳐 보고 문장 5개를 만들어 주세요. 각 문장은 관찰한 숫자, 외부 근거, 의미, 다음 액션을 포함해야 합니다. 근거가 약한 부분은 “추가 확인 필요”라고 표시해 주세요.

## 제출 안내
Padlet에는 완성본이 아니어도 됩니다. 리서치 질문만 만든 상태, 소스만 모은 상태, 보고 문장 초안도 제출 가능합니다. 막힌 지점이 있으면 “어느 단계에서 막혔는지”만 남겨도 됩니다.
