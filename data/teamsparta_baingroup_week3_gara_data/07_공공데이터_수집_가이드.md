# 공공데이터 가져오기 가이드

목표는 “외부 데이터를 많이 모으기”가 아니라 내부 차트를 해석할 기준점을 하나 붙이는 것입니다. 내부 데이터만 보면 높은지 낮은지 판단하기 어렵기 때문에, 공공데이터는 비교 기준 또는 추가 확인 질문을 만드는 재료로 씁니다.

## data.go.kr에서 가져오는 순서

1. 크롬에서 `data.go.kr`에 접속합니다.
2. 검색어를 하나만 입력합니다.
   - 예: 지역 인구, 교육기관, 평생교육, 고용, 상권, 청년, 직업훈련
3. 파일데이터인지 OpenAPI인지 확인합니다.
   - 파일데이터: CSV, XLSX, ZIP을 내려받아 바로 확인합니다.
   - OpenAPI: 활용신청 후 서비스키가 필요할 수 있습니다. 수업 중에는 설명 문서와 샘플만 써도 됩니다.
4. 데이터명, 제공기관, 기준일, 사용한 열을 메모합니다.
5. 내부 데이터와 직접 연결하지 말고, 비교 기준점으로만 씁니다.

## 오늘 수업에서 바로 쓸 수 있는 방식

1. 내부 차트에서 궁금한 점을 먼저 고릅니다.
   - 예: 특정 센터는 유입은 많은데 전환율이 낮다.
2. 공공데이터포털에서 관련 기준점을 찾습니다.
   - 예: 지역 인구, 교육기관 수, 직업훈련, 평생교육, 청년/중장년 인구.
3. 데이터를 다 붙이지 말고, 비교에 필요한 열만 기록합니다.
   - 데이터명, 제공기관, 기준일, 사용한 열, 내부 차트와 연결한 이유.
4. NotebookLM에는 “설명 문서 + 내가 뽑은 핵심 열 메모”만 넣어도 됩니다.

## 오늘 실습에서 쓸 수 있는 질문

- 특정 지역의 인구 또는 교육 수요가 높은데, 해당 센터의 유입/전환도 함께 높은가?
- 외부 지역 지표와 내부 센터 성과가 어긋나는 곳은 어디인가?
- 외부 데이터 기준으로 다음에 더 확인해야 할 센터 또는 채널은 무엇인가?
